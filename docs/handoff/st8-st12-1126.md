## What a builder should start from

1. FO-10: hook the loop **body**, not the scheduler, and return early when `FarHold` says the object's lot is parked.
   An object with no lot or in an inventory is never paused. Tree first (docs/331 §4.9), then pets.
2. Demotion rule to add to FO's pass: do not park a lot with a pending door-close task, a running Store table dealer
   task, or a yielding alarm task of its owner (docs/346 §2).
3. Lot hub: patch `LotManager.RemoveLot` (prefix) and `LotManager.AddLot` (postfix) rather than subscribing to the
   world events; the shutdown loop removes lots after `LotManager` unsubscribed, and subscriber order flips on the
   second world.
4. `Lot.MoveIn` / `MoveOut` postfix = scope change: promote the lot at once.
5. Existing CP-3 / CP-4 consumers keep rows of a bulldozed lot until the next world event (docs/348 §5.3, Q5).
