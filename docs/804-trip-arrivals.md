# 804: `visitarrive`, `visitonlot`, `gohomeshell`, trip arrivals without EA's route (visitarrive, visitonlot ON; gohomeshell off)

Answer: three ts3fixes switches (`visitarrive` and `visitonlot` default ON since the 2026-11-20 import, `gohomeshell` default off: it needs the native `[EaCrashFixes] LotLevelPastEnd=1`, ini default 0) end an unseen townie's trip the way EA's own arrival does, minus the route plan that the shortcut already made pointless. All three change nothing for household, selected or unknown-scope Sims, and nothing with the switch off.

- `visitarrive` (tuning `kVisitArrive`): after the community-visit shortcut (`visit`) placed an unseen townie on the lot, EA's `VisitCommunityLot.Run` still routed to the front door or planned to the lot: a 110-150 ms plan for a Sim already standing at the lot's entry point. `Arrive()` follows EA's Run line by line without the route (carpool wait, formal / workplace outfit, `NumSuccess`, "do something after arriving" when autonomous, grouping situation). A Sim carrying a child keeps EA's Run. Counter [1292].
- `visitonlot` (tuning `kVisitOnLot`): a townie that already stands on the lot it visits arrives with the same `Arrive()`, without the route to the front door. Counter [1293]. Never fired in the author's runs (see the PR): the draft keeps it only so the test can find out whether the case exists.
- `gohomeshell` (tuning `kGoHomeShell`): an unseen townie whose home is an apartment (a lot with a building shell) was always left to EA's walk, because a random spot on the lot can be inside the closed building. With the switch on, `GoHomeHook` places it on a `SafeSpot` inside the apartment's own rooms (`Lot.GetRandomPosition(true, false)`, same floor, same lot, out of view) and GoHome succeeds without a route. No room point, no such spot, another floor or lot, or a spot in view: EA's walk. Counters [1294] asked, [1295] placed, [1296] walked, split [1297] near or no room point, [1298] no safe spot, [1299] other floor or lot, [1300] spot in view.

Dependency: the earlier local version of `gohomeshell` (a spot in front of the shell door, EA walking the Sim in) crashed in EA's slot attach on freed physics in Bridgeport apartment games; the native `LotLevelPastEnd` fix of PR #449 clamps that read. The version here stays off the door and the elevator, but it should be tested with #449's switch on.
