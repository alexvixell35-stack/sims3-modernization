# v0.3.2 release notes (2026-11-25, maintenance release)

Player notes: `CHANGELOG.md` section `## v0.3.2` (the GitHub release body; CI appends `docs/PLAYERS.md`). Setting names, switches and known issues: `v0.3.2-dev.md`.

A maintenance release on v0.3.1: fixes for stuck Sims, crashes and mod compatibility, many fixes for Sims you do not control (by Dalexlol and twopointjj), and groundwork for big worlds. Sims you play keep the game's own behavior. No headline speed claim and no new timing run: the v0.3.1 numbers in the README stand.
